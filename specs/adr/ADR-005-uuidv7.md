# ADR-005 — UUIDv7 identifiers

- Status: accepted
- Date: 2026-08-16

## Decision

All entity identifiers generated by Credbound use canonical UUIDv7. The
generator combines a Unix timestamp in milliseconds, a monotonic 12-bit counter
for calls within the same millisecond, and 62 random bits. If the clock moves
backward, it retains the last value; if the counter is exhausted, it logically
advances by one millisecond.

WebAuthn credential IDs, public PAT prefixes, recovery codes, and pagination
cursors are not entity identifiers and retain their protocol-defined formats.

## Consequences

IDs are chronologically sortable within a process without exposing a global
counter. PostgreSQL uses the `uuid` type; SQLite uses a `TEXT` column with
application-level validation.
